Match the lane to risk.

A lane describes the work’s risk and scope. It constrains model, effort, destination, and review; it is not a price tier.

The six lanes

Lane, task, executor, and review
LaneUse forWho runs it & review
R0Trivial text or documentation; no behaviour change.Claude, or opted-in external text executor. A trivial Claude text task may use no reviewer if you will read it; external drafts require Claude review.
R1Small, low-risk change with tests.Claude or Codex if routing allows it; opted-in external executor for text only. Follow the reviewer matrix.
R2Ordinary feature or fix in a few files.Claude or allowed Codex. External text only with the project’s R2 level; Claude reviews it.
R3Large or cross-cutting work.Claude or allowed Codex at the configured effort. Codex gets the lane’s Claude reviewer; Claude follows its allowed reviewer matrix.
R4Authentication, permissions, personal data, or project-sensitive terms.Local Claude only: Opus 5.5, Fable 5.2 or Fable 5.1. At least high effort, a different Claude reviewer, and human review before merge.
R5Highest-risk work.The same fixed guards as R4, including independent Claude review and human review.

R4/R5 stay with Claude. The mandate requires an adversarial check and explicit human review before merging. Codex, external writers, cloud, API credits, and permission bypass cannot route around that requirement.

Mark sensitive work explicitly

Agents should set corsia: "R4" (or "R5") and sensibile: true. Do not rely on detection alone.

The detector checks title, brief, and background for words beginning with auth or permess, plus login, password, passwd, mfa, otp, csrf, PII, dati personali, codice fiscale, and project terms.

English permissions and personal data do not trigger the fixed list. Conversely, author can match auth. Reword a false match only when the task truly is non-sensitive. Setting sensibile: false does not cancel detection.

Rules always win

A lane does not grant access to a provider or model. The project must allow the executor, model, effort and reviewer; an external provider must also be opted in and connected. Invalid or unreadable rules block starts.

Sensitive Fable authors use Opus 5.5 review; sensitive Opus authors use Fable 5.2 review. Human review remains required. Child chips inherit their director's constraints, which can only tighten. Chains never accept sensitive work. Read about director mode.
