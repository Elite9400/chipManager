You approve the work.

Give work a clear path.

A Claude Code plugin that turns proposed tasks into chips you can review, start, and follow through to completion.

You choose who works, how hard they reason, and where they run. Project rules check each start.

Set up chipManager

Your first three steps

  1. Install the plugin.

    Add the marketplace, then install for you or your project. Get the commands.

  2. Run /chipmanager --setup.

    Choose providers, sign in, and apply your settings. The project also needs routing rules.

  3. Start your chips.

    Ask Claude to propose tasks. Read each brief and choose Start or Start all.

You decide at each hand-off

  1. ProposeOne task, one brief
  2. Approve & startYour choice
  3. DeliverA result to review
  4. CompleteMerged or marked done

Delivered is not completed. A finished session still needs its result accepted. Follow the full life cycle.
