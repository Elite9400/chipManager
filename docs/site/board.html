You approve the work.
Project rules check the start.

Your project, in a browser.

The project board is a local HTML snapshot of work. It is separate from this public documentation site.

Turn it onRead the boardChoose summaries deliberatelyKeep the board private

Turn it on

Open Settings → Board, choose On or With summaries, and press Apply. The default is Off. When ready, use Open board in the header, or b.

The panel writes <data folder>/board/<project>-<hash>/index.html on its 30-second cycle when something changed. Reload the browser page to see the new snapshot.

Read the board

Work is grouped as waiting for you, in progress, next, and done. Completed work covers the last 30 days; the board also shows the last 15 commits from the base branch and milestones when available.

Open a task’s disclosure for its plan, rebuilt and original brief, background, lane, dependencies, execution choices, expected reviewer, reported review outcome, and dates. piano points to a repository .md or .txt file displayed on the board; put that path in the brief too if the worker needs it.

Review outcomes are reported by a session, not independently verified by the board. Start and completion decisions remain in the panel.

Choose summaries deliberately

The HTML is built by code and costs no model tokens. Optional summaries call Haiku for changed tasks: about 700 input and 120 output tokens per task, capped at 5 per minute and 100 per day.

Summaries send title, brief, and dependency titles to Claude. They do not run with Local network only or with Claude disabled. Leave summaries off if you only need the underlying task details.

Keep the board private

The board is never published by the mod. It has no scripts or remote resources, uses a restrictive content policy, and masks attempt tokens. It follows system light/dark appearance and uses keyboard-accessible disclosures.

It can contain private briefs and project context. Keep its data folder outside repositories; do not copy it into docs/site/ or upload it as a documentation screenshot.
