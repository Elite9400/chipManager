Account and Project

Where a setting belongs
LayerSettings
AccountConnections, usage thresholds, manual budgets, work-mode defaults, API credits budget and per-run cap, FreeLLMAPI endpoint, and language.
ProjectAllowed providers, local-network-only policy, milestones, balancing profile and weights, board, destination advisor, external-text level, and stricter limits.

Project work mode can override account work mode. Project thresholds, API month limit, and per-run cap can only be stricter than the account; a looser value is refused. Remove restriction restores inheritance.

Work mode

Choose default effort per lane, a Codex execution sandbox, parallel sessions (1–8), a suggested auditor, and cross-review preferences for R0–R2. R4/R5 effort cannot drop below high.

Recommended restores defaults (or inheritance for a project). Economy lowers effort on small lanes and avoids suggesting an auditor. Quality raises effort and suggests more review. These presets are separate from balancing profiles.

Director and pipeline controls are planned for 2.2.0; they are not present here.

Thresholds and budgets

Warning and critical thresholds describe provider usage percentages. The default pair is 70% / 90%. Over critical, the balancer sharply reduces that provider’s margin for omitted choices; it preserves explicit choices. Start all shows the warning and asks whether to proceed.

Manual limits record what you declare, with their time and unit. They are not live measurements and do not change automatic choices when they cross a threshold.

API Claude credits

  1. Use a dedicated Anthropic API key with a low Console workspace spend limit.
  2. Enter it only in /config → chip-manager → Anthropic API (credits).
  3. In Settings → Execution, set the account’s monthly budget and per-run cap. Apply the draft.
  4. Optionally set tighter project limits. Choose Here on API credits on a non-sensitive Claude chip.

Each run reserves its cap before launch, against account and project limits. The account spend log covers all projects. A run may exceed its cap slightly; the Console workspace limit is the hard boundary.

The key is available to the running agent and its tools. The temporary key file is removed after the run; this does not revoke the key. Revoke a suspected copied key in the Console. The panel shows only set or missing.

Connect with guided steps

Use /chipmanager --setup or Settings → Execution for the offered sign-in and preparation steps. A step shows what is missing and its outcome. Some steps open a browser, wait for you, or offer a command to copy if the host cannot run it.

Keys stay in native sensitive options. Connections and sign-ins are separate from the settings draft. The mod does not rewrite Claude Code settings files; if one blocks a lane, it names the source for you to change.

Local network only (soloLocale) blocks new LLM launches and external probes by the mod, including the local proxy. It is not an “Ollama only” mode.

Draft and immediate writes

When changes take effect
ActionWrites when
Ordinary settings editsAfter validation, stay in a draft until Apply. Discard changes drops the draft.
Settings proposed by a sessionOnly when requested by you; populate the draft. You review and Apply. Proposals cannot add keys, enable providers, or loosen guards.
Manual budgetsImmediately through their own controls.
Connections / sign-insWhen their own action is performed.
Weight proposal → ApplyImmediately through that proposal’s action; its own Undo is available.

Discard changes does not undo immediate writes. Leaving Settings with a draft asks Apply, Discard, or Stay. If another session changed the same fields, nothing is overwritten: choose Reload and reapply my draft, or Discard my draft.
